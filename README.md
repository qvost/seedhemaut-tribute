# Seedhe Maut — Tribute Experience

Interactive tribute site for New Delhi hip-hop duo **Seedhe Maut** (Encore ABJ & Calm), built with React, TypeScript, GSAP, Lenis, and Framer Motion.

## Live

https://seedhe-maut-theta.vercel.app

## Features

- Kinetic brutalist hero with 3D-tilting live photography and `MAUT MODE` grain toggle
- Dual opposing vertical infinite sliders for Calm and Encore ABJ
- Scroll-driven discography arc covering 8 releases (*2 Ka Pahada* through *DL91 FM*)
- Interactive album sleeve inspector with searchable tracklists, collaborator credits, and streaming links
- Sound-house & label showcase (*Spit Dope Inc.*, *Azadi Records*, *Sez on the Beat*, *The MVMNT*, *Hurricane*, *DL91 Era*)

## Local Development

```bash
npm install
npm run dev
```

To create a production build:

```bash
npm run build
```
